# SnowRunner CC HUD 1.1.4 — регистрация и публикация на mod.io

Это инструкция для **HUD-версии** с ручной установкой ASI. Страница на mod.io помогает найти мод и скачать установщик, но подписка во внутриигровом браузере не устанавливает ASI рядом с EXE. Поддержка консолей не заявляется. Публикация страницы пользователем ещё не выполнена.

## Регистрация

1. Откройте [SnowRunner на mod.io](https://mod.io/g/snowrunner) и нажмите **Log in**.
2. Выберите предложенный способ входа: например, Epic Games, Steam или e-mail. Если уже пользовались mod.io из игры, войдите в существующий аккаунт; при входе по почте используйте тот же адрес.
3. Для e-mail введите полученный пятизначный код. Укажите имя пользователя, когда сайт предложит его выбрать. Пароль Epic/Steam вводите только в форме входа соответствующего провайдера.
4. Если для загрузки потребуется подтверждение почты, выполните его через настройки аккаунта и письмо mod.io.

Порядок входа описан в [справке mod.io](https://support.mod.io/hc/en-us/articles/9110718302607-How-do-I-create-a-mod-io-account); возможное дополнительное подтверждение — в [документации проверки аккаунта](https://docs.mod.io/authentication/verification/).

## Что подготовить

- Название: **SnowRunner Cruise control - Native HUD (PC, Manual Install)**.
- Краткое описание: **Native cruise-control HUD with F6 toggle. PC only, manual ASI installation.**
- Полное английское описание: [MODIO_DESCRIPTION_EN.md](MODIO_DESCRIPTION_EN.md). Перед публикацией замените формулировку о загрузке установщика на фактически доступный файл/ссылку.
- Собственные скриншоты: строка выключена и включена, желательно общий вид HUD. Для русской/английской/французской надписей используйте только реально проверенные снимки. Не заявляйте проверку языков, которую ещё не выполняли.
- Архив: `SnowRunnerCC-HUD-1.1.4-Setup.zip`, версия `1.1.4`, платформа **Windows / PC**. Консольные платформы не отмечайте.
- Ссылка на [репозиторий](https://github.com/TRSteep/SR_CruiseControl) и на [HUD 1.1.4 с установщиком](https://github.com/TRSteep/SR_CruiseControl/releases/tag/ingame-v1.1.4).

Установщик и ZIP собираются командой из корня репозитория:

```powershell
.\ingame\installer\build.ps1
```

Файлы появятся в `ingame/build/installer/1.1.4`. Для пересборки самого HUD добавьте `-RebuildHud`. В каталоге также находятся `SHA256SUMS.txt`, сведения о сборке, инструкции и лицензии. В ZIP не включены тестовые файлы, журналы, резервные копии и игровые ресурсы.

## Создание страницы

1. На странице [SnowRunner](https://mod.io/g/snowrunner) нажмите **Add mod**. Официальный мастер описан у [Saber](https://expeditions-guides.saber.games/truck_modding/getting_started/sample_mod_by_the_game/uploading_mod_to_mod_io/).
2. Заполните название, краткое и полное описание. В первой строке явно оставьте **PC ONLY — MANUAL INSTALLATION**. Укажите совместимость только с проверенным Epic Games 44.1 EXE.
3. Добавьте обложку и скриншоты. Из предложенных текущим интерфейсом тегов выберите **Manual** и подходящие теги интерфейса/инструментов, если они доступны. Не обозначайте пакет как автоматически устанавливаемую машину или карту.
4. На шаге **File manager** выберите ZIP установщика, укажите Windows/PC, версию `1.1.4` и примечания к выпуску. Если площадка не принимает такой ручной пакет с EXE, оставьте разрешённую страницу со ссылкой на GitHub Releases либо уточните допустимый формат у поддержки mod.io. Не загружайте фиктивный игровой пакет ради кнопки подписки.
5. Сначала выберите **Hidden**, чтобы проверить страницу до публичного размещения. Откройте скачивание своего файла, проверьте контрольную сумму и убедитесь, что инструкция объясняет внешний запуск установщика.
6. Когда описание, скачивание и установка проверены, измените видимость на **Public**. Если мод отправлен на проверку площадкой, дождитесь её результата. Проверка и срок одобрения заранее не гарантируются.

Официальный мастер описывает публикацию игровых пакетов с последующей подпиской; для нашего ASI применяется только создание страницы/размещение разрешённого ручного скачивания. Наша установка остаётся внешней.

## Обновления

Используйте ту же страницу мода. В её редакторе добавьте новую версию файла через File manager, обновите версию и changelog, проверьте ссылку на скачивание. Пользователи ручного ASI-пакета запускают новый установщик самостоятельно; подписка не обновляет ASI автоматически.

Перед публикацией проверьте английское описание, актуальную версию, поддерживаемый EXE, наличие лицензий, рабочую ссылку на исходники и SHA256. Для публикации используйте архив с коммитом релизного тега и sourceTreeDirty=false в BUILD_INFO.json.
