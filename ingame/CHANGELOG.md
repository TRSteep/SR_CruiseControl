# SnowRunner Cruise control (SnowRunner CC) — HUD

## 1.1.4

- Полный установщик Windows x64: выбор папки игры, проверка EXE и вложений по SHA256, сохранение INI, резервные копии, отключение прежней накладки/диагностики, удаление ASI и откат при ошибке. Неизвестный `dinput8.dll` не заменяется.
- Название строки по языку игрового HUD: «КРУИЗ КОНТРОЛЬ», «CRUISE CONTROL», «RÉGULATEUR DE VITESSE». Для остальных языков — английский. Текст подгоняется по ширине до значка.
- Исправлена передача ручного газа круизу: зажать W → нажать F6 → отпустить W. Автоповтор исходного нажатия не отключает круиз; физическое отпускание подтверждает удержание. Следующее отдельное нажатие W отключает круиз.
- S/N, повторная F6, меню и потеря фокуса продолжают отключать удержание. Ошибка повторного ввода снимает активное состояние и сохраняет необходимую очистку ввода.
- Документация установки, описание и инструкция публикации на mod.io. ASI требует внешней установки и не устанавливается подпиской в игре.

Совместимость: Windows x64, точная проверенная сборка Epic Games / SnowRunner 44.1. Установщик требует .NET Framework 4.x и не подписан. Совместимость с другими сборками не подтверждена.

Проверки: 38 memory/ABI, 215 native UI, 827 session, 416 icon, 27 localisation, 176 state/input и 65 installer — успешно. Окно установщика, автоматическое нахождение игры и справка проверены визуально. Базовый HUD проверен пользователем ранее; переключение всех языков и исправленный сценарий W → F6 ещё не подтверждены живой проверкой пользователя.
