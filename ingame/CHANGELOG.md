# SnowRunner Cruise control (SnowRunner CC) — HUD

## Экспериментальный запуск без списка разрешённых хешей

Отдельная сборка `-Autopilot -ResolveSignatures -AllowUnreviewed` отключает блокировку по Epic SHA256. Сигнатуры, PE-границы, связи функций и загруженные байты продолжают проверяться. В INI доступны Stage=0 (наблюдение), Stage=1 (HUD без ввода), Stage=2 (HUD и управление). По умолчанию выбран Stage=0. В журнал добавлены этапы запуска и немедленно сохраняемые контрольные точки UI. Имена ASI/INI/журнала отдельные; стабильный установщик не ослаблен.

Без запуска Steam фактическая причина её отказа не установлена: новый пакет нужен для получения журнала и локализации сбоя. Поддержка Steam не сертифицирована.

## В разработке — сигнатуры и диагностика совместимости

- Общий сканер x64 PE: маскированные сигнатуры десяти функций, проверка границ исполняемых секций и runtime function entries, строковой ссылки фабрики и связи Movie destructor/Advance через vtable. Неоднозначный результат не выбирается автоматически.
- Отдельный диагностический EXE и необязательный ASI без перехватов, вызовов AS3 и клавиатурного ввода. Пакет для Steam-тестера содержит EXE, инструкцию и метаданные.
- Опциональный экспериментальный HUD с разрешением адресов по сигнатурам и повторной проверкой загруженных байтов. ABI разрешён только для уже проверенного Epic EXE; неизвестная сборка остаётся диагностической.
- Проверено на Epic 44.1: все десять адресов и структурные связи; 36 проверок сканера и 7 проверок привязки на частной копии образа. Проверки существующего HUD проходят. Установленные игровые файлы не менялись.

Это не опубликованный универсальный релиз. Для следующего этапа нужны журналы и затем живые проверки пользователей Steam; установщик пока сохраняет прежнее ограничение EXE.

## 1.1.5

- Исправлено скрытие строки при отключении штатного HUD: visible и alpha копируются со штатного ручника после обновления игры. Вместе со строкой скрываются значок и квадрат F6; при включении HUD они возвращаются без переключения круиза.
- Скрытие интерфейса сохраняет состояние удержания газа. Нет перехвата клавиши `\`: используется состояние штатного интерфейса, включая переназначенные клавиши.
- Добавлены проверки скрытия отдельных строк при видимом контейнере, затухания, повторного включения, сбоев чтения/записи и повторных циклов.

Пользователь подтвердил в игре скрытие/возврат строки вместе со штатным HUD и работу разных языков. Проверки: 44 memory/ABI, 215 UI, 2596 session, 416 icon, 27 localisation, 176 input и 65 installer — успешно.

## 1.1.4

- Полный установщик Windows x64: выбор папки игры, проверка EXE и вложений по SHA256, сохранение INI, резервные копии, отключение прежней накладки/диагностики, удаление ASI и откат при ошибке. Неизвестный `dinput8.dll` не заменяется.
- Название строки по языку игрового HUD: «КРУИЗ КОНТРОЛЬ», «CRUISE CONTROL», «RÉGULATEUR DE VITESSE». Для остальных языков — английский. Текст подгоняется по ширине до значка.
- Исправлена передача ручного газа круизу: зажать W → нажать F6 → отпустить W. Автоповтор исходного нажатия не отключает круиз; физическое отпускание подтверждает удержание. Следующее отдельное нажатие W отключает круиз.
- S/N, повторная F6, меню и потеря фокуса продолжают отключать удержание. Ошибка повторного ввода снимает активное состояние и сохраняет необходимую очистку ввода.
- Документация установки, описание и инструкция публикации на mod.io. ASI требует внешней установки и не устанавливается подпиской в игре.

Совместимость: Windows x64, точная проверенная сборка Epic Games / SnowRunner 44.1. Установщик требует .NET Framework 4.x и не подписан. Совместимость с другими сборками не подтверждена.

Проверки: 38 memory/ABI, 215 native UI, 827 session, 416 icon, 27 localisation, 176 state/input и 65 installer — успешно. Окно установщика, автоматическое нахождение игры и справка проверены визуально. Базовый HUD проверен пользователем ранее; переключение всех языков и исправленный сценарий W → F6 ещё не подтверждены живой проверкой пользователя.
