# SnowRunner Cruise control (SnowRunner CC) — HUD 1.1.4: установка

Нативный ASI-мод для Windows x64. Строка «КРУИЗ КОНТРОЛЬ» и отдельный квадратик F6 создаются внутри штатного Scaleform HUD: двигаются вместе с соседними строками и скрываются вместе с автомобильным интерфейсом.

Справа внутри строки находится значок спидометра. При включении зелёным становится значок, а надпись сохраняет светлый цвет.

Язык надписи выбирается по штатному HUD игры: русский — «КРУИЗ КОНТРОЛЬ», английский — «CRUISE CONTROL», французский — «RÉGULATEUR DE VITESSE». Для остальных языков используется английский. При смене языка надпись обновляется автоматически; длинный текст уменьшается по ширине до значка.

Проверено на **Epic Games, SnowRunner 44.1**. Мод проверяет точный SHA256 SnowRunner.exe; другие сборки, включая Steam, не подтверждены. При несовпадении EXE перехваты и управление не запускаются. Хеш поддержанной сборки:

```text
a3cb442ec138eb2eb7e335e5c80e376766550740e49e233ac9eace035e182285
```

Это удержание полного газа, а не поддержание заданной скорости или автоматическое движение по маршруту.

Текущий релиз — **[HUD 1.1.4](https://github.com/TRSteep/SR_CruiseControl/releases/tag/ingame-v1.1.4)**. Имена ASI/INI/журнала и секция `[Autopilot]` сохранены для совместимости; название приложения — SnowRunner Cruise control (SnowRunner CC).

В разделе Assets доступны EXE установщика, ZIP установщика и архив для ручной установки. Архивы Source code содержат исходники, а не готовую программу.

## Установщик

Скачайте [SnowRunnerCC-HUD-1.1.4-Setup.exe](https://github.com/TRSteep/SR_CruiseControl/releases/download/ingame-v1.1.4/SnowRunnerCC-HUD-1.1.4-Setup.exe) или [ZIP установщика](https://github.com/TRSteep/SR_CruiseControl/releases/download/ingame-v1.1.4/SnowRunnerCC-HUD-1.1.4-Setup.zip) и распакуйте его.

Закройте игру, запустите установщик, выберите корневую папку SnowRunner или папку с EXE и нажмите «Установить / обновить». Требуется .NET Framework 4.x. Установщик проверяет точный поддержанный EXE, сохраняет INI, создаёт резервные копии рядом с игрой и отключает прежние overlay/test ASI. Неизвестный `dinput8.dll` не заменяет: для другого совместимого загрузчика используйте ручные шаги ниже. Если нужны права записи, мастер предложит перезапуск от администратора.

«Удалить HUD» переносит проверенный ASI в резервную папку. INI, общий загрузчик и резервные копии сохраняются; прежняя накладка не включается. Мастер не добавляет запись в «Установленные приложения» Windows; для удаления запустите его повторно. Установщик не подписан цифровой подписью.

[Исходники и сборка установщика](installer/README.md). [Как разместить HUD на mod.io](MODIO_PUBLISH_RU.md).

## Ручная установка

1. Закройте SnowRunner.
2. Скачайте **SnowRunnerCC-HUD-ingame-v1.1.4-win-x64.zip** из GitHub Releases и распакуйте.
3. Откройте папку **рядом с SnowRunner.exe**. Обычно это:

   ```text
   <папка игры>\en_us\Sources\Bin
   ```

   В проверенной установке: `D:\Games\SnowRunner\en_us\Sources\Bin`.
4. Уберите старые версии из этой папки, если они есть: переименуйте `SnowRunnerAutopilot.asi` в `SnowRunnerAutopilot.asi.disabled`, а `SnowRunnerScaleformProbe.asi` — в `SnowRunnerScaleformProbe.asi.disabled`. Иначе старая накладка или TEST-мод будут загружаться вместе с новой версией.
5. Скопируйте рядом с EXE:

   ```text
   SnowRunnerNativeAutopilot.asi
   SnowRunnerNativeAutopilot.ini
   dinput8.dll
   ```

   Если `dinput8.dll` уже установлен другим модом, **сохраните существующий загрузчик и не заменяйте его вслепую**. При совместимом x64 ASI-загрузчике достаточно новых ASI/INI. В архиве находится Ultimate ASI Loader 10.0.2 для установки с нуля.
6. Запустите игру обычным способом и загрузите сохранение. Над ручником появится «КРУИЗ КОНТРОЛЬ» (в русской версии игры), справа — отдельный квадрат F6.

Не устанавливайте ASI через браузер модов/mod.io: файлы должны находиться рядом с EXE. Старый скрипт `ingame/install.ps1` из исходников относится к версии с наложением; для этого релиза используйте шаги выше.

## Обновление

Закройте игру и замените `SnowRunnerNativeAutopilot.asi`. Существующий `SnowRunnerNativeAutopilot.ini` сохраните, если меняли клавишу. INI старой версии с наложением имеет другое имя и не используется новым модом. При первом переходе со старой версии скопируйте новый INI из архива.

Сохранения игры и файлы PAK менять не требуется.

Если W уже зажата, нажмите F6 и отпустите W: круиз подхватит газ и продолжит работать. Автоповтор исходного нажатия W не отключает круиз; следующее отдельное нажатие W передаёт газ водителю. S/N, повторная F6 и остальные клавиши отключения сохраняют действие.

## Управление

- **F6** — включить/выключить удержание газа; значок становится зелёным, текст остаётся светлым.
- **W** — отключить автопилот и передать газ водителю до отпускания W.
- **S** — отключить автопилот и тормозить.
- **N** — отключить автопилот и передать игре нажатие переключателя двигателя.
- **Esc, Enter, M, F1, F4**, переключение в другое окно — отключить автопилот.

После Alt+Tab автопилот сам не включается. Газ должен быть назначен на физическую W, тормоз/задний ход — на S. Геймпад и руль не отслеживаются. Отключение двигателя мышью не определяется; сброс по N срабатывает при физическом нажатии этой клавиши.

Для нового включения нужен видимый автомобильный HUD. Управление и обновление строки работают в отдельных потоках; клавиатурный обработчик не вызывает Scaleform.

## Настройки

Файл `SnowRunnerNativeAutopilot.ini` рядом с EXE:

```ini
[Autopilot]
Enabled=1
ToggleKey=117
```

`117` — F6, `118` — F7, `119` — F8. Поддерживаются F2–F12, кроме F4. Текст отдельного квадратика меняется вместе с назначением. `Enabled=0` выключает автопилот. После изменения настроек перезапустите игру.

## Если строка не появилась

Проверьте, что файлы лежат рядом с EXE и старые ASI отключены. Прочитайте `SnowRunnerNativeAutopilot.log` в этой же папке:

- `Unsupported EXE` — сборка игры не совпадает с поддержанной; управление не запускается.
- `Native input thread started` — поток управления запущен.
- `Native frames=... HUD=1` — обновляется видимый автомобильный HUD.
- `UI-keybadge.end ... ok=1` — штатный квадратик клавиши создан.

Проверка: включите F6 и отключите повторной F6 или S; затем проверьте W/N и переключение в другое окно.

## Удаление

Закройте игру и удалите `SnowRunnerNativeAutopilot.asi` и `SnowRunnerNativeAutopilot.ini`. Журнал можно удалить отдельно. `dinput8.dll` удаляйте только если он не используется другими модами. Выгрузка ASI на лету не поддерживается.

В пакет включены лицензии MinHook и Ultimate ASI Loader. Игровые шрифты, текстуры и GFX-файлы не распространяются: мод использует ресурсы установленной игры.
