# SnowRunner CC — установщик HUD 1.1.4

Один EXE для установки текущего нативного HUD. Системный .NET Framework 4.x / Windows x64; отдельная установка компилятора или SDK для запуска не нужна. Интерфейс установщика — русский или английский по языку Windows. Язык самого HUD выбирается отдельно, по интерфейсу игры.

Из корня репозитория:

```powershell
.\ingame\installer\build.ps1
```

`-RebuildHud` сначала пересобирает ASI и запускает его проверки. Без этого параметра используется готовый ASI, версия заголовка сборки проверяется по `ingame/VERSION`. Результат — `ingame/build/installer/1.1.4/SnowRunnerCC-HUD-1.1.4-Setup.exe` и ZIP для ручного распространения, плюс контрольные суммы и BUILD_INFO.json. Сведения о сборке включают SHA256 вложенных ASI/INI/загрузчика, коммит и признак изменённых исходников.

## Поведение

- Предлагает найденную установку через манифест Epic или каталоги Steam; можно выбрать папку игры или `Sources/Bin` вручную. Нахождение папки не означает совместимость: устанавливается только точный проверенный Epic 44.1 EXE.
- Блокирует изменения при работающем SnowRunner. Проверяет SHA256 EXE и вложенных файлов до установки.
- Сохраняет существующий INI. Существующий загрузчик с известным хешем оставляет; неизвестный `dinput8.dll` не заменяет. Для другого совместимого загрузчика используйте [ручную установку](../INSTALL_NATIVE.md).
- Создаёт `SnowRunnerCC_Backups/<дата>-<id>` рядом с игровым EXE. Сохраняет существующие файлы до изменений. Старые overlay/test ASI переименовывает в `.asi.disabled.cc-<id>`; обратно сам не включает.
- При ошибке откатывает выполненные изменения; если откат тоже не удался, сообщает путь резервной копии и ошибки.
- Кнопка удаления проверяет хеш установленного ASI и переносит его в резервную папку. Изменённый ASI оставляет. Настройки, загрузчик, прежние резервные копии и другие моды сохраняются. После обновления EXE игры удаление остаётся доступным.
- Не меняет сохранения, PAK, EXE игры или реестр. Это переносимый мастер установки: записи в списке «Установленные приложения» Windows нет. Для удаления снова запустите мастер.
- Запускается с обычными правами. Если папка защищена, предлагает повторный запуск через штатный UAC. Установщик не подписан цифровой подписью.

`InstallerTests.cs` использует искусственные папки и EXE, не настоящую игру. Проверяются установка/обновление, сохранение INI, неизвестный загрузчик, несовместимый EXE, запущенная игра, повреждённое вложение, удаление и откат на разных этапах. `--verify-package` проверяет встроенные файлы без установки и без окна.

Иконка установщика — собственный значок проекта; лицензии MinHook и Ultimate ASI Loader вложены в EXE (кнопка справки) и ZIP. Пошаговая публикация: [MODIO_PUBLISH_RU.md](../MODIO_PUBLISH_RU.md).
