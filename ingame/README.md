# SnowRunner Cruise control (SnowRunner CC) — HUD

**Версия исходников: 1.1.5. Последний готовый релиз: [HUD 1.1.4](https://github.com/TRSteep/SR_CruiseControl/releases/tag/ingame-v1.1.4).** Версия 1.1.5 с исправлением скрытия строки доступна в исходниках; отдельный релиз с её файлами ещё не опубликован.

Нативный ASI-мод для Windows x64. Загружается вместе с SnowRunner и добавляет строку «КРУИЗ КОНТРОЛЬ» на один шаг выше ручника внутри штатного Scaleform HUD. Фон, шрифт, наклон и движение используются из игры. Значок спидометра справа становится зелёным при включении, надпись остаётся светлой. Клавиша F6 отображается отдельным штатным квадратиком.

Это удержание полного газа, а не поддержание заданной скорости или движение по маршруту.

## Совместимость

Поддержана точная проверенная сборка **Epic Games / SnowRunner 44.1 / Windows x64**. До установки перехватов проверяется SHA256 EXE. Другие сборки, включая Steam и Game Pass, не подтверждены. Обновление EXE может потребовать обновления мода; совместимость с другими модами зависит от их реализации.

Для установщика нужен .NET Framework 4.x. Сохранения, PAK и игровой EXE не изменяются.

## Установка готового релиза

1. Закройте SnowRunner.
2. Скачайте [установщик HUD 1.1.4](https://github.com/TRSteep/SR_CruiseControl/releases/download/ingame-v1.1.4/SnowRunnerCC-HUD-1.1.4-Setup.exe) или ZIP установщика из [Assets релиза](https://github.com/TRSteep/SR_CruiseControl/releases/tag/ingame-v1.1.4).
3. Выберите папку игры или папку с `SnowRunner.exe`. Обычно это `<папка игры>/en_us/Sources/Bin`.
4. Нажмите **Install / update / Установить / обновить**. При необходимости мастер предложит перезапуск с правами администратора.
5. Запустите SnowRunner обычным способом.

Установщик сохраняет INI, создаёт резервные копии, отключает прежние overlay/test ASI и не заменяет неизвестный `dinput8.dll`. Он не подписан цифровой подписью. Для другого совместимого x64 ASI-загрузчика используйте [ручную установку](INSTALL_NATIVE.md). Подписка в игровом браузере mod.io этот ASI не устанавливает.

Для версии **1.1.5** соберите мод и установщик по инструкции ниже. Установщик появится в `build/installer/1.1.5/SnowRunnerCC-HUD-1.1.5-Setup.exe`.

## Управление

| Клавиша | Действие |
| --- | --- |
| **F6** | Включить/выключить удержание газа |
| **W** | Отключить круиз и передать газ водителю до отпускания W |
| **S** | Отключить круиз и тормозить |
| **N** | Отключить круиз и передать игре нажатие переключателя двигателя |
| **Esc, Enter, M, F1, F4**, потеря фокуса | Отключить круиз |
| `\` по умолчанию | Штатное скрытие/возврат HUD; в исходниках 1.1.5 строка круиза следует этому состоянию |

Если W уже зажата, нажмите F6 и отпустите W: круиз подхватит газ. Автоповтор исходного нажатия W игнорируется; следующее отдельное нажатие W отключит круиз. После Alt+Tab круиз сам не включается.

В версии 1.1.5 строка, значок и F6 скрываются вместе со штатными строками и возвращаются без переключения круиза. Удержание газа при скрытии HUD сохраняется. Отслеживается состояние игрового интерфейса, поэтому работает и переназначенная клавиша скрытия.

Газ должен быть назначен на физическую W, тормоз — S. Геймпад, руль и отключение двигателя мышью не отслеживаются. N отменяет удержание при физическом нажатии, включая запуск двигателя.

## Настройки и языки

Файл `SnowRunnerNativeAutopilot.ini` рядом с игровым EXE:

```ini
[Autopilot]
Enabled=1
ToggleKey=117
```

`117` — F6, `118` — F7. Поддерживаются F2–F12, кроме F4; после изменения перезапустите игру. Подсказка на HUD меняется вместе с назначением. `Enabled=0` отключает мод.

Язык строки определяется по штатному HUD игры: русский — «КРУИЗ КОНТРОЛЬ», английский — «CRUISE CONTROL», французский — «RÉGULATEUR DE VITESSE». Для остальных языков используется английский. Длинная надпись подгоняется по ширине до значка. Язык Windows и раскладка клавиатуры не выбирают язык строки.

## Обновление, удаление и диагностика

Для обновления закройте игру и запустите новый установщик; ваш INI сохраняется. Для удаления снова запустите мастер и выберите **Remove HUD / Удалить HUD**: проверенный ASI переместится в резервную папку. INI, общий загрузчик и резервные копии останутся. Записи в списке «Установленные приложения» Windows нет.

При ручном обновлении замените ASI и сохраните свой INI. При ручном удалении уберите ASI; загрузчик удаляйте только если он не нужен другим модам. Подробности — [INSTALL_NATIVE.md](INSTALL_NATIVE.md).

Журнал `SnowRunnerNativeAutopilot.log` создаётся рядом с EXE. `Unsupported EXE` означает неподдержанную сборку. `UI-hud.visibility.end` сообщает синхронизацию скрытия/возврата строки в версии 1.1.5. При сообщении об ошибке укажите версию мода, магазин/сборку игры и приложите этот журнал.

## Сборка из исходников

Windows x64, MSYS2 UCRT64 GCC. Из корня репозитория:

```powershell
.\ingame\prepare-dependencies.ps1
.\ingame\experimental\scaleform\build.ps1 -Autopilot -Package
.\ingame\installer\build.ps1
```

ASI: `build/scaleform-probe/SnowRunnerNativeAutopilot.asi`. Установщик и ZIP: `build/installer/1.1.5`. Разработческий ZIP ASI не содержит ASI-загрузчика. Версия хранится в `VERSION`; имена ASI/INI/журнала и секция `[Autopilot]` сохранены для совместимости.

Актуальные исходники находятся в `experimental/scaleform`; общий контроллер — `src/CruiseState.h`. Корневые `build.ps1` и `install.ps1` в этой папке относятся к прежнему DirectX-наложению и не собирают текущий HUD. [Техническая документация](experimental/scaleform/README.md), [установщик](installer/README.md), [список изменений](CHANGELOG.md).

Автоматические проверки покрывают управление, ABI/ссылки, локализацию и видимость. Базовый HUD проверен пользователем в игре; живая проверка скрытия/возврата в версии 1.1.5 пока не подтверждена.

В пакеты включены лицензии [MinHook](vendor/minhook-1.3.4/LICENSE.txt) и [Ultimate ASI Loader](vendor/asi-loader-v10.0.2/LICENSE.txt). Игровые GFX, шрифты и текстуры не распространяются. [Публикация на mod.io](MODIO_PUBLISH_RU.md), [английское описание страницы](MODIO_DESCRIPTION_EN.md).
