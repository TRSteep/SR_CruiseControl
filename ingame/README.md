# SnowRunner Cruise control (SnowRunner CC) — HUD 1.1.5

Нативный внутриигровой мод для Windows x64. Локальная сборка: **HUD 1.1.5**. Последний опубликованный релиз — [HUD 1.1.4](https://github.com/TRSteep/SR_CruiseControl/releases/tag/ingame-v1.1.4), без исправления скрытия HUD. [Инструкция установки и обновления](INSTALL_NATIVE.md).

Строка «КРУИЗ КОНТРОЛЬ» создаётся внутри штатного Scaleform HUD на один шаг выше ручника. Фон, шрифт, наклон, анимация и скрытие используют игровую панель. Справа внутри строки находится векторный спидометр: при включении он становится зелёным, надпись остаётся светлой. Клавиша F6 отображается отдельным штатным квадратиком справа.

Это удержание полного газа, а не поддержание заданной скорости или движение по маршруту. Проверено на Epic Games / SnowRunner 44.1. Точный SHA256 EXE проверяется до установки перехватов; другие сборки не подтверждены.

Локально доступны установщик EXE, ZIP установщика и разработческий архив ASI. Версия 1.1.5 на GitHub ещё не опубликована.

## Установка и управление

Для HUD подготовлен [установщик](installer/README.md): выбор папки игры, проверка совместимости, сохранение настроек, резервное копирование и удаление ASI. Локальный установщик — `build/installer/1.1.5/SnowRunnerCC-HUD-1.1.5-Setup.exe`. [Регистрация и публикация на mod.io](MODIO_PUBLISH_RU.md); [английское описание страницы](MODIO_DESCRIPTION_EN.md). Установка остаётся внешней, через подписку в игре этот ASI не устанавливается.

Готовый пакет: `SnowRunnerCC-HUD-ingame-v1.1.5-win-x64.zip`. ASI, INI и совместимый x64 ASI-загрузчик помещаются рядом с `SnowRunner.exe`. Подробные шаги, обновление, диагностика и удаление — в [INSTALL_NATIVE.md](INSTALL_NATIVE.md).

- **F6** — включить/выключить удержание газа.
- **W** — передать газ водителю.
- **S/N** — отключить удержание.
- **Esc, Enter, M, F1, F4**, потеря фокуса — отключить; возврат в игру сам не включает круиз.

Газ должен быть назначен на физическую W, тормоз — на S. Сброс по N относится к физической клавише. Геймпад, руль и выключение двигателя мышью не отслеживаются. Настройка `ToggleKey` меняет также подсказку на HUD.

Если W уже зажата, нажмите F6 и отпустите W: круиз подхватит газ и продолжит работать. Автоповтор исходного нажатия W не отключает круиз; следующее отдельное нажатие W передаёт газ водителю. S/N, повторная F6 и остальные клавиши отключения сохраняют действие.

## Сборка HUD

Из корня репозитория, Windows x64 / MSYS2 UCRT64 GCC:

```powershell
.\ingame\prepare-dependencies.ps1
.\ingame\experimental\scaleform\build.ps1 -Autopilot -Package
```

Исходники — `experimental/scaleform`; общий контроллер — `src/CruiseState.h`. Результат — `build/scaleform-probe/SnowRunnerNativeAutopilot.asi`. [Устройство HUD и проверки](experimental/scaleform/README.md).

Имена `SnowRunnerNativeAutopilot.asi`, `.ini`, `.log` и секция `[Autopilot]` сохранены для совместимости. Название приложения — SnowRunner Cruise control, сокращённо SnowRunner CC. Версия HUD хранится в `VERSION`.

Старые исходники DirectX-наложения в `src/Autopilot.cpp` и скрипты `build.ps1` / `install.ps1` сохранены как история разработки и не собирают текущий HUD. Для актуального релиза используйте команду выше и INSTALL_NATIVE.md.

В релиз включены лицензии [MinHook](https://github.com/TsudaKageyu/minhook/tree/v1.3.4) и [Ultimate ASI Loader 10.0.2](https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases/tag/v10.0.2). Игровые GFX, шрифты и текстуры не распространяются.

Язык надписи выбирается по штатному HUD игры: русский — «КРУИЗ КОНТРОЛЬ», английский — «CRUISE CONTROL», французский — «RÉGULATEUR DE VITESSE». Для остальных языков используется английский. При смене языка надпись обновляется автоматически; длинный текст уменьшается по ширине до значка.

При отключении штатного HUD (по умолчанию `\`) строка круиза, значок и F6 скрываются вместе с игровыми строками. Повторное включение HUD возвращает их. Скрытие интерфейса сохраняет управление газом. Исправление требует живой проверки в игре.
